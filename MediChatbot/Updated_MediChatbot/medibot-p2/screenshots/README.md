## Screenshot Guidelines

### 📸 Capture Requirements
1. **High Resolution** - Minimum 1920x1080 for desktop screenshots
2. **Clean Interface** - Hide personal information and sensitive data
3. **Representative Data** - Use sample medical documents (non-sensitive)
4. **Professional Quality** - Clear, well-lit, properly cropped

### 🔒 Security Requirements
- **Hide API Keys** - Blur or mask any visible API keys
- **Remove Personal Data** - No real patient information or personal emails
- **Generic Usernames** - Use placeholder names like "demo@example.com"
- **Sample Documents** - Use publicly available medical document samples

### 📝 Naming Convention
- Use descriptive, lowercase names with hyphens
- Include relevant keywords for easy identification
- Keep filenames under 50 characters
- Use PNG format for UI screenshots, JPG for photos

### 🎯 Content Focus
Each screenshot should clearly demonstrate:
- **Functionality** - What the feature does
- **User Interface** - How users interact with it
- **Results** - What output/outcome is produced
- **Professional Appearance** - Clean, organized, intuitive design
