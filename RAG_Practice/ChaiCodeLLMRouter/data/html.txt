HTML (HyperText Markup Language) is the standard markup language for documents designed to be displayed in a web browser. It can be assisted by technologies such as Cascading Style Sheets (CSS) and scripting languages such as JavaScript.

## Core Concepts
- **Element**: The basic building block of HTML. An element is defined by a start tag, some content, and an end tag.
- **Tag**: Tags are keywords designated by angle brackets like <html>, <head>, <body>, <title>, etc.
- **Attribute**: Attributes provide additional information about HTML elements.

## Structure
A basic HTML document has the following structure:
<!DOCTYPE html>
<html>
<head>
<title>Page Title</title>
</head>
<body>
<h1>This is a Heading</h1>
<p>This is a paragraph.</p>
</body>
</html>

## HTML5 Semantic Elements
HTML5 introduced semantic elements like <header>, <footer>, <article>, and <section> to better define the structure and layout of web pages.
